# Nikita Sham Gurav — Portfolio

Live: https://nikita3909.github.io

## Run locally
```
npm install
npm run dev
```
Open http://localhost:3000

## Screenshots
Put real screenshots (with sensitive data blurred) in `public/images/` using these names:
sales-analytics.png, command-center.png, production-pulse.png, sales-reconciliation.png,
capacity-assessment.png, o2d-tracking.png, sales-suite.png, sales-crm.png,
admin-tracker.png, wfh-tracker.png

If an image is missing, the card shows a sample chart instead.

## Deploy
Push to the `main` branch of the `Nikita3909.github.io` repo. GitHub Actions builds and
publishes the site (Settings → Pages → Source: GitHub Actions).
